# 🔬 Eureka — Interactive STEM & Science Discovery Portal

Eureka is an interactive science discovery and STEM education platform featuring visual physics simulations, biology concepts, mathematical models, and exploratory modules for learners.

## 🌟 Features
- **Visual Experiments**: Interactive animations and demonstrations of fundamental scientific principles.
- **Concept Modules**: Deep dives into physics, biology, chemistry, and computational thinking.
- **Responsive Learning Interface**: Optimized for both classroom whiteboards and personal mobile devices.
- **Lightweight & Fast**: Built with vanilla web technologies for zero friction and instant loading.

## 🛠️ Tech Stack
- **HTML5 Canvas / CSS3**: High-performance interactive visualizations and modern responsive styling.
- **JavaScript**: Mathematical simulations, interactive state handling, and dynamic animations.
